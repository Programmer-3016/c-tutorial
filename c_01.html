Unit 1: Basics of Programming

Introduction to Programming using C

Last updated: 31 Oct 2025

This topic covers the fundamentals of programming, the origin and features of C, its real‑world applications, and how it compares to C++. By the end, you should be able to explain what C is, why it still matters, and how a basic C program is structured and executed.

What is Programming?

Programming is the process of writing instructions that a computer can execute to perform a specific task. These instructions follow a defined logic and are written in a programming language.

Every program works on a simple cycle: take input, apply processing, and produce an output. The step-by-step plan behind this process is called an algorithm.

What is C Language?

C is a general‑purpose, procedural programming language developed by Dennis Ritchie in 1972 at Bell Laboratories. It was designed to write the UNIX operating system — a language that could operate close to hardware while remaining portable.

C is a compiled language, which makes it faster than interpreted languages. It provides low‑level memory access through pointers and supports structured programming. Because it combines high‑level readability with low‑level control, C is often called a "middle‑level language".

📌 Note: C versions include ANSI C (C89), C99, C11, and C17 with small improvements while the core stays the same.

Importance of C

Dozens of programming languages exist today, yet C remains the recommended starting point in most curricula. The reason is simple — C does not hide how the machine works. It makes you deal with memory, types, and structure directly, which builds a stronger foundation than any high‑level language can.

  • Syntax foundation: Java, C++, C#, PHP, and JavaScript all derive their syntax from C.
  • Hardware understanding: Concepts like memory allocation, pointers, and compilation are best learned through C.
  • Performance awareness: C teaches you to think about memory usage, data storage, and execution efficiency.
  • Academic relevance: Most university curricula and competitive exams use C as the first programming language.

Applications of C

C is not limited to textbooks — it powers much of the software and hardware you interact with daily. Wherever speed, low‑level control, or minimal resource usage is required, C is usually the language behind it.

  • Operating Systems: Linux, UNIX, and parts of Windows and macOS are written in C.
  • Embedded Systems: Microcontrollers, printers, and automotive ECUs run firmware in C.
  • Compilers: GCC, Clang, and the CPython interpreter are implemented in C.
  • Databases: MySQL, PostgreSQL, and SQLite are built using C.
  • Game Engines: id Tech (Doom, Quake) was originally written in C.
  • IoT & Networking: Network drivers, protocol stacks, and sensor firmware rely on C.

How C Differs from C++

C++ was developed by Bjarne Stroustrup as an extension of C with object‑oriented features. Key differences frequently asked in exams:

Aspect C C++
Programming Approach Procedural Procedural + OOP
Program Structure Functions Classes and objects
Encapsulation Not supported Supported
Inheritance Not supported Supported
Input/Output printf / scanf cout / cin
Memory Management malloc / free new / delete

First C Program

A C program starts with preprocessor directives, followed by main(), which holds the executable statements.

main.c
Output
Ready
Line‑by‑Line Explanation
#include <stdio.h>

Preprocessor directive — includes the Standard I/O header for printf() and scanf().

C provides several built‑in header files, each serving a different purpose. Some commonly used ones:

  • <stdio.h> — Input/Output functions (printf, scanf)
  • <stdlib.h> — Memory allocation, conversions (malloc, atoi)
  • <string.h> — String operations (strlen, strcpy)
  • <math.h> — Mathematical functions (sqrt, pow)
  • <ctype.h> — Character handling (isalpha, toupper)
int main()

Entry point of every C program. int means it returns an integer value.

printf("Hello, World!");

Library function that prints the string literal inside double quotes to the console.

return 0;

Returns 0 to the OS, indicating successful execution. Non‑zero means an error.

  • 3. Differentiate between C and C++ on at least six parameters with a comparison table.

Topic Summary

  • Programming: Writing instructions for a computer using a defined language and logic.
  • C: A compiled, procedural language created by Dennis Ritchie (1972, Bell Labs). Often called a middle‑level language.
  • Used in: Operating systems, embedded systems, compilers, databases, IoT.
  • Structure: #include → main() → statements → return 0;
  • C vs C++: C is procedural only; C++ adds object‑oriented features.
