# C Programming Tutorial 💻
> **Introduction to Programming using C — Programming Hub**

An interactive, responsive C programming learning module featuring dark/light themes, code editor with Monaco support, interactive topics syllabus, and syntax guides.

## 🚀 Live Demo
Deployed on Vercel.

## 🛠️ Features
- **Monaco Code Editor integration** with responsive fallback
- **Interactive Syllabus** covering Units 1 to 8 of C Programming
- **Dark / Light theme** with persistent preference
- **Quick Jump navigation** and Table of Contents
- **Responsive layout** optimized for desktop, tablet, and mobile
